Belépés

A szerkesztő a weboldal GitHub-tárhelyére menti a változásokat. Ehhez egyszer létre kell hoznod egy belépőkulcsot (tokent), ami csak ehhez az egy repóhoz ad hozzáférést.

Hogyan hozok létre kulcsot? (kb. 1 perc, csak egyszer kell)
  1. Nyisd meg ezt az oldalt (GitHub-belépés kellhet): Új kulcs létrehozása ↗
  2. Token name: pl. Emcrem admin · Expiration: pl. 1 év
  3. Repository access: Only select repositories → válaszd ki: emcrem
  4. Permissions → Repository permissions:
    • Contents: Read and write (kötelező)
    • Actions: Read-only (ajánlott – így látod, mikor került ki az oldalra)
  5. Kattints a Generate token gombra, másold ki a kulcsot (github_pat_…), és illeszd be lent.
